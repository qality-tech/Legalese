# Legalese

The paperwork for the **qality.tech** Discord bot — the Discord application `wiki-bot`
(application ID `1573304492886204447`).

- **[NOTICE.md](NOTICE.md)** — what the bot reads, where it files it, what it cannot see, and how to
  take it away. This is the only document here that is in force.

It runs in one server, which is ours. It is not offered for installation by anyone else, which is why
there is no licence, no acceptable-use policy and no terms of service in this repository — those are
documents about strangers, and there are no strangers.

We are not a company, so there are no terms of service and no privacy policy: there is no entity that
could be the provider in one or the operator in the other. Drafts written on the assumption that there
was such an entity are kept in the application's own repository, marked as shelved, and are not
published here.

This is a pre-release experiment run by the people who run the qality.tech Discord server. The notice
changes when the experiment does, and the date at the top of it changes with it.

Questions: open an issue here, or ask in the server.
